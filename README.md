# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

- ローカルリポジトリは、自分のパソコン内にあるリポジトリで、個人の作業環境で変更履歴を管理する場所
- リモートリポジトリは、ネットワーク上にあるリポジトリで、複数人でコードを共有・管理する場所

## プッシュとマージの違いは何でしょうか？

- プッシュ（Push）は、ローカルの変更記録をリモートリポジトリへ送信する
- マージ（Merge）は、枝分かれしたブランチの変更を別のブランチに統合する

## コミットとプッシュの違い

- コミット（Commit）は、ファイルの変更をローカルに記録する操作
- プッシュ（Push）は、ローカルの記録をネットワーク上（リモート）に送信する操作

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

- 「何を変更したのか」「なぜ変更したのか」が、他の人や未来の自分が見ても一目で分かるように、具体的かつ簡潔に書くのが最適

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

- ローカルでのマージは、自分のパソコン上で直接ブランチを合流させるため、レビューなしで即座に統合される
- プルリクエストでのマージは、GitHub上で変更内容を他のメンバーに確認（レビュー）してもらい、承認を得てから安全に合流させるフロー

## コンフリクトを起こしてしまった場合、どう対処すべきですか？

- コンフリクトしたファイルを開き、Gitが挿入した記号（<<<<<<< など）を目印にして、残すべき正しいコードを手動で選ぶ
- 不要なコードと記号を削除して保存した後、再度コミットを行って解決する。
